
# Hackathon Game - Codex Instructions

## Project Overview
This is an independent 2D game project built with Godot 4.

The game will be published on itch.io as a browser game and may also be released as a Windows executable.

The final game concept has not been selected.

## Technology
- Engine: Godot 4
- Language: GDScript
- Renderer: Compatibility
- Platforms: Windows and HTML5
- Target: Smooth 60 FPS gameplay
- Editor: Visual Studio Code

## Development Standards
- Use Godot 4-compatible APIs.
- Prefer statically typed GDScript.
- Keep code modular and maintainable.
- Separate scenes, scripts, assets, and resources.
- Use descriptive file, node, and variable names.
- Avoid unnecessary dependencies.
- Do not use C#.
- Preserve working features when making changes.

## Performance Requirements
- Target a consistent 60 FPS.
- Avoid unnecessary work every frame.
- Use lightweight 2D graphics.
- Prefer efficient physics and collision handling.
- Avoid excessive dynamic lighting.
- Profile before attempting major optimizations.
- Consider HTML5 performance and compatibility.

## Workflow
1. Inspect relevant files before editing.
2. Explain the intended changes for major tasks.
3. Make focused, testable changes.
4. Run available validation checks.
5. Report errors and unfinished work.
6. Do not claim a feature works unless tested.
7. Never delete important files without permission.
8. Ask before installing external dependencies.
9. Do not overwrite unrelated work.
10. Use Git checkpoints for working milestones.

## Current Development Phase
We are configuring the workstation and project.

Do not implement game mechanics, levels, combat, or assets until the final game concept is approved.

## Goal
Develop a polished, engaging, performant indie game with reliable controls, clear gameplay, and strong visual presentation.
